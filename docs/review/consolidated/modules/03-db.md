# 模块 03 · db（数据访问层）

## 目的

用 SQLAlchemy 2.x + psycopg3 管 10 张表，对外只暴露"读写两个引擎 + 一组强制行级过滤的查询函数"，让 Text-to-SQL 与业务 API 走不同权限的数据库角色。

## 关键结论

1. **表分为业务表与基础设施表**：
   - `BUSINESS_MODELS` 8 张：`User` `Product` `Order` `OrderItem` `Refund` `StockMovement` `Ticket` `Employee`（`app/db/models.py:433`）；
   - `INFRA_MODELS` 2 张：`QueueDeadLetter`、`Account`（`app/db/models.py:452`）；
   - 合计 `ALL_MODELS` 10 张（`app/db/models.py:454`）。
   > ⚠️ 与 `docs/architecture.md:118-135` 相比，架构文档只列了 8 张业务表 + `accounts`，**漏了 `queue_dead_letters`**。正文以代码为准。
2. **连接池参数固定**：`POOL_SIZE=5`、`MAX_OVERFLOW=10`、`POOL_TIMEOUT=30`（借不到连接最多等 30s 后快速失败）、`POOL_RECYCLE=1800`（`app/db/session.py:27-30`）。上限 15 条连接，配合只读角色实现"库层面兜底"。
3. **读写两个引擎**：`get_write_engine()` / `get_read_engine()`（`app/db/session.py:97-103`）。`DATABASE_READ_URL` 留空时读引擎回落到写引擎 —— 此时"只读"只在命名上成立。已验证办法：两者 `is` 比较应为 `False`（`docs/runbook/6.tools-runbook.md` §2.5）。
4. **行级过滤是代码级强制，不靠调用方自觉**：`app/db/queries.py:52` 的 `assert_row_filtered()` 检查 `Select` 里有没有 `user_id` 条件、有没有 `LIMIT`；`MAX_LIMIT=200`（`app/db/queries.py:29`）。
5. **`accounts` 禁止进入 SQL 白名单**：`app/security/policy.py:123` 的 `NEVER_IN_SQL_WHITELIST = frozenset({"accounts"})`，并由 `tests/security/test_sql_whitelist.py` 反向断言。
6. **迁移用 Alembic**，`env.py` 从 `Settings` 注入连接串，**不把密码写进 `alembic.ini`**。

   当前迁移是**单链、无分叉**（每个文件只指向一个 `down_revision`）：

   | 顺序 | revision | 文件名 | 内容 |

   | 1 | `1d0329d8d747` | `20260923_..._init_business_tables.py` | 8 张业务表 |
   | 2 | `29d823809e4f` | `20260929_..._add_idempotency_key_....py` | `tickets`/`refunds` 幂等键唯一约束 |

## 待办 / 已知边界

- `DATABASE_READ_URL` 未配置时读路径会落到写角色上（`app/config/settings.py:215` 注释已承认）。生产必须配。
- 表结构与 `docs/architecture.md` §5 的差异：架构文档缺 `queue_dead_letters`；`accounts` 在架构文档里单列（做法正确）。

## 坑

| 坑 | 症状 | 依据 |
|---|---|---|
| URL 方言写错（`postgresql://` vs `postgresql+psycopg://`） | 装的是 psycopg3，却按 psycopg2 找驱动 | `app/db/session.py:33` |
| 以为"只读"是配置出来的 | 读引擎 == 写引擎，SQL 里 DELETE 也能执行 | `app/db/session.py:83` 的 `_read_url()` |
| 改模型不加迁移 | `test_no_pending_migration_against_models` 红 | `tests/test_db_migrations.py` |
