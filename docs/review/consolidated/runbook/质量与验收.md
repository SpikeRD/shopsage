## 关键结论

### A. 验收顺序（换机器或大改动后）

| # | 验收项 | 命令 | 判据 |
|---|---|---|---|
| 1 | 工具链 | `python/uv/node/npm/git --version` | 版本齐 |
| 2 | 依赖同步 | `uv sync --locked` | 无改动 |
| 3 | 依赖栈 | `docker compose ... ps` | 依赖服务 healthy |
| 4 | 数据库 | `alembic upgrade head` + `scripts.db_check --check` | 退出码 0 |
| 5 | 后端 | `curl /health` | 200 且 `status=ok` |
| 6 | 后端全量 | `uv run pytest -q` | 全绿（连不上库时 db 用例自动 skip） |
| 7 | 语料 | `scripts.load_knowledge_base` | 文档数是 8 |
| 8 | 前端 | `cd web && npm test && npm run build` | 全绿 + 构建通过 |
| 9 | 真链路 | `node tests/run-live.mjs` | 全通过 |

### B. 评测（`14.eval-runbook.md`）

```bash
uv run python -m eval.run --suite rag --dataset rag_golden_v1
uv run python -m eval.run --suite agent --dataset agent_golden_v1
uv run python -m eval.run --suite compare
```

阈值全在代码：`recall ≥0.70`、`faithfulness ≥0.70`、`relevance ≥0.60`、多 Agent 最小增益 `0.15`（`app/eval/settings.py:37-42`）；退出码 0/1/2 分别表示 通过/低于阈值/跑不了。
