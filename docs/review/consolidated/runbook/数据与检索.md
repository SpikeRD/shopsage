# 运行手册 · 数据与检索

> 吸收：`docs/runbook/3.db-runbook.md`（629 行）、`10.rag-runbook.md`（1167 行）、`13.cache-runbook.md`（1332 行）→ 本文。

## 目的

把"库 → 迁移 → 种子 → 语料 → 检索 → 缓存"这条链一次走通，并给出每一步的**判据**（怎么算做对了）。

## 关键结论

### A. 顺序不能换

```
起依赖（postgres/pgvector、redis） → alembic upgrade head → scripts.seed
   → scripts.load_knowledge_base（灌语料） → 检索可用 → 语料变更后重新灌并推进 corpus_revision
```

- 漏了灌语料：检索全空、缓存写入"没找到"的答案 → 后续会踩 `issues/010`。
- 灌库**必须**推进 `corpus_revision`，否则旧缓存永远不失效（`app/cache/corpus.py:219 bump_after_ingest`）。

### B. 每一步的判据

| 步骤 | 命令 | 判据（期望输出） |
|---|---|---|
| 依赖就绪 | `docker compose -f infra/docker-compose.dev.yml --project-directory . ps` | 4 个服务 `Up ... (healthy)` |
| pgvector 可用 | `SELECT extversion FROM pg_extension WHERE extname='vector'` | 一行 `0.7.x` |
| 迁移到位 | `uv run alembic upgrade head` | head = `c7a4e2f9b1d8` |
| 种子数据 | `uv run python -m scripts.seed` | 幂等，重复执行结果一致 |
| 现场核查 | `uv run python -m scripts.db_check --check` | 缺表/行数不足 → 退出码 1 |
| 只读角色生效 | 工具里 `SELECT current_user` | `shopsage_readonly` |
| 语料在位 | `scripts/load_knowledge_base` 后查活跃片段数 | 文档声称 **61 片段 / 8 文档**（⚠️ 本次未复核片段数） |
| 检索有据 | 问答带回 `citations` | 出处形如 `docs/kb/退货政策.md #c9138e3a458ef2420` |

### C. 检索侧的关键设计（`10.rag-runbook.md`）

- **中文切词**：n-gram 词表 + tsvector，**SQL 内手算 BM25**（不是 `ts_rank`）；
- **索引**：向量用 HNSW（不是 IVFFlat，因为空表建 IVFFlat 会退化）；关键词用 GIN；
- **融合**：RRF（`RAG_RRF_K=60`），候选 `RAG_CANDIDATES=30`；
- **rerank 降级**：`off` / `local` / `api` 三档，`local` 依赖 sentence-transformers（默认没装）。
- **维度三处同步**：`EMBEDDING_DIM` / `RAG_VECTOR_DIM` / 表 `vector(1024)`，改一处就会在第一次写入时报错。

### D. 缓存侧的关键设计（`13.cache-runbook.md`）

- 判定五道闸 + 灰区（`[0.70, 0.85)`）；阈值必须**换 embedding 后重标定**。
- 降级矩阵四格都可用，但**降级必须可见**（`CacheHealth` + `/health` 的 cache 组件）。
- 跨机器时钟：时间戳对齐数据库那一边。
- **空结果不进缓存**（`issues/010` 追加的产品决策）。

## 待办 / 已知边界

- ⚠️ 片段数（61）与"top-1 命中 10/12"等数字均来自**旧后端时代**的实测，本次未复跑 → `../03-待确认清单.md` Q-07。
- `RAG_RERANK` 在代码默认是 `local`（`app/config/settings.py:278`），而 `.env` / `env.list.example` 都设成 `off` —— 意味着**当前生产不做重排**，检索质量依赖 RRF。

## 坑（各手册里最值钱的几条）

| 坑 | 后果 | 出处 |
|---|---|---|
| 维度三处不一致 | 首次写入向量时抛错 | `app/rag/store.py:254-262` |
| `to_tsvector` 做成生成列 | 索引"有时对有时错"（函数是 stable 不是 immutable） | 迁移 `20261010_*` 注释 |
| 灌库不推进版本 | 缓存永久返回旧答案 | `issues/010` |
| 空结果写进缓存 | 知识库修好了，客户还是被告知"没找到" | `issues/010` |
| 换 embedding 不重建索引 | 语义检索全错，且**看起来正常** | `app/rag/store.py:167` |
| 缓存读路径与写路径参数指纹不一致 | 写了永远不命中 | `app/cache/semantic.py:256-262` |
