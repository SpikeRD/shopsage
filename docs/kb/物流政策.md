# 物流与配送政策

## 1. 配送范围与时效

1.1 本店默认发顺丰速运，全国（不含港澳台）均可配送。

1.2 一般情况下，现货商品在付款后 24 小时内出库，出库后 1~3 个工作日送达。

1.3 偏远地区（新疆、西藏、内蒙古部分旗县）需要 3~5 个工作日，节假日顺延。

1.4 预售商品的发货时间以商品详情页标注为准，不受上述时效约束。

## 2. 运费标准

2.1 单笔订单实付满 99 元免运费；未满 99 元收取 10 元运费。

2.2 大家电、家具等大件商品按体积计费，具体金额在下单时展示。

2.3 退货产生的运费承担方见《退货与换货政策》第 2 条与第 7 条。

## 3. 签收与验货

3.1 建议当面验货后再签收。签收即视为外观完好，但**不影响**后续的质量问题退换货权利。

3.2 包裹外包装明显破损时，可拒收并联系客服，本店免费重发。

3.3 包裹签收后 48 小时内可申请破损理赔，需提供开箱视频与外包装照片。

## 4. 配送地址修改

4.1 未发货的订单可在订单详情页点击「修改地址」自助修改，每个订单最多修改一次。

4.2 已发货的订单无法修改收货地址，可联系客服协助与快递协商（不保证成功）。

4.3 因地址填写错误导致包裹退回的，重新发货的运费由买家承担。
