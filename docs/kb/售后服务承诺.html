售后服务承诺

本节用于演示 HTML 文档的解析与分块：标题会保留为 Markdown 风格，脚本与样式会被剔除。

1. 服务响应

在线客服工作时间 09:00~21:00，非工作时间的留言将在次日 10:00 前回复。

工单类问题（退款、理赔）承诺 24 小时内首次响应，48 小时内给出处理方案。

2. 售后举证要求

  • 破损理赔：外包装照片 + 开箱视频（连续拍摄，不要中断）。
  • 功能故障：故障现象视频 + 商品序列号照片。
  • 少发漏发：拆箱全貌照片 + 装箱单照片。

3. 争议处理

双方对责任归属有争议时，以厂家检测报告或第三方检测机构结论为准。

检测为非人为损坏的，检测费用由本店承担；反之由买家承担。
